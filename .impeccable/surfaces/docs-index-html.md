# Landing page: docs/index.html

Scope: the public landing page on GitHub Pages. Mode: Persuade.
Audience: Xiaomi / Redmi owners fed up with MIUI ads. Job: decide to install. Action: download the APK from GitHub Releases (latest).
Message: Ads gone, nothing lost (steps history, weather, real alarm, widgets stay), and it is reversible.
Proof: real screenshots from the Redmi Note 7 on a plain wallpaper; honest limits and tested-on facts. No testimonials, counts or ratings (none exist).
Avoid: the generic app-landing template (gradient hero, floating phone mockup, three feature cards).
Memorable moment: the thread's post #1 with the attached APK and the "Ads gone. Nothing lost." hook.

## Direction contract

THESIS: The page is the first post of an Android release thread, the document Redmi owners already read before installing anything: title with device tags, OP post, attached APK, reserved posts #2/#3, changelog, known issues. It refuses the app-landing arrangement of hero, floating mockup and feature-card row.

OWN-WORLD: Forum page grey ground (#E7E8EA), post paper (#FBFBFC) with 1px rules, graphite (#1B1D20) header bars and OP badge, silver (#B9BEC4) dividers from the app icon, one green ink (#1F8F4E) for downloads and ticks, nothing else. Heavy grotesk for the hook, plain system sans for posts, mono only for file names and commands. Post anatomy: author column, post number, tag chips, attachment tray, fold-flat spoiler blocks.

STORY: Visitor sees a release post for their phone, reads "Ads gone. Nothing lost.", sees real screenshots, learns what stays (steps, alarm, weather), what Ad Shield does and how to undo it, reads honest known issues, downloads the APK.

FIRST VIEWPORT: Graphite thread bar with post jump links; breadcrumb; thread title with tags; post #1 with author column at left and, at right, the hook at display scale, then the attached-file tray with the green Download button (primary action, above the fold), then three real screenshots as attachment thumbnails.

Signature interaction: the swipe diagram and spoilers unfold in place.
